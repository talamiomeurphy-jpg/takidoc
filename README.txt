Installation :
1. Décompressez l’archive.
2. Copiez les fichiers dans le dossier public approprié du projet (ou adaptez les chemins selon la structure réelle).
3. Reliez les liens du pied de page aux fichiers correspondants.
4. Testez tous les liens et l’affichage sur mobile.

À vérifier avant publication :
- confirmer que Render est bien l’hébergeur utilisé dans la configuration actuelle ;
- confirmer le parcours de livraison des PDF, les tarifs et la monnaie affichée au paiement ;
- vérifier les prestataires et cookies réellement présents dans le code ;
- vérifier le statut juridique et les obligations locales applicables ;
- faire relire les textes par un professionnel compétent en République du Congo.

Les textes sont des projets d’information générale, pas un avis juridique et ne garantissent pas à eux seuls la conformité légale.
